# 🚀 EcoWarriors

## 📌 Visão Geral
**EcoWarriors** é um jogo **2D de nave** desenvolvido como projeto acadêmico no **6º semestre de Engenharia da Computação**, na disciplina de **Programação Orientada a Objetos (POO)**.  

O jogo tem como missão **proteger a Terra contra lixos espaciais**, ilustrando de forma lúdica os impactos negativos do descarte inadequado e reforçando a importância da preservação ambiental.  

## 🎮 Funcionalidades
- Controle da nave para destruir lixos espaciais antes que atinjam a Terra.  
- Sistema de pontuação baseado na quantidade de lixos destruídos.  
- Diferentes tipos de lixos, representando ameaças variadas.  
- **Suporte a celular e controle de videogame**, garantindo acessibilidade.  
- Feedback visual durante acertos.  

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** C#  
- **Game Engine:** Unity (2D)  
- **Paradigma:** Programação Orientada a Objetos (POO)
